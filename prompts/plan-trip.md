# Plan-Trip Prompt Template

Paste this into Claude Code (or use `/skill plan-trip`) and fill in the
brackets. Any field can be left as `[?]` and Claude will ask for it.

---

Plan a trip with these details:

- **Relationship:** [couple / friends / family — note group size & ages]
- **Dates:** [start date – end date, e.g. Oct 10 – Oct 13, 2026]
- **Budget:** [total or per person, e.g. $2500 total for two]
- **Main purpose:** [anniversary / relaxation / adventure / food / sightseeing / birthday]
- **Destination:** [city, or "suggest options" if you want recommendations]

Produce a complete day-by-day plan following the TravelAO plan structure:
overview, transportation, accommodation (2–3 options), daily itinerary,
restaurants (2–3 per day), places to visit, budget breakdown, and practical
notes. Match every recommendation to the relationship and the trip purpose.
